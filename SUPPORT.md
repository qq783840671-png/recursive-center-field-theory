# Support

This is a personal research project with best-effort maintenance. There is no service-level agreement, guaranteed response time, or private consulting entitlement.

## Choose the right channel

| Need | Channel |
|---|---|
| Reproducible Skill, runtime, address, test, or packaging failure | **Runtime or Skill failure** issue form |
| A contradiction, counterexample, scope error, or evidence challenge | **Theory or evidence challenge** issue form |
| Broken link, unclear wording, translation, or navigation problem | **Documentation problem** issue form |
| Open-ended question, interpretation, application idea, or comparison | [GitHub Discussions](https://github.com/qq783840671-png/recursive-center-field-theory/discussions) after it is enabled |
| Sensitive vulnerability | Follow [SECURITY.md](SECURITY.md); never post details publicly |
| Conduct or abuse concern | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Please do not use an implementation bug report to request proof that the complete philosophy is true, or use a philosophical disagreement to report a script defect. Contributions that cross layers should state each layer separately.

## Before asking for help

1. Check the [release scope and evidence boundaries](docs/release-scope.md).
2. Confirm the exact plugin, Skill, theory document, and version involved.
3. Remove private material and reduce the example to the smallest useful case.
4. Search existing issues and discussions once the repository is online.
