# Changelog

## 0.5.0-alpha.1 — 2026-09-03

- Renamed the public product to **Focus Field**.
- Reduced the public package to one canonical `$focus` Skill.
- Replaced the duplicated public theory archive with one concise English theory.
- Added a product-first quickstart, five positive and three negative submission cases, minimal legal pages, and visual metadata.
- Published the six-condition Focus / ordinary × none / RAG / knowledge-graph evaluation harness.
- Made the public value path explicit: locate the field, derive the governing question, choose one valid next move, and revise the position when evidence changes.
- Added lightweight personal-decision and research-question behavior cases without adding a new Skill or evaluation service.
- Preserved performance claims as hypotheses until controlled real runs are available.

Earlier local candidates remain in internal project history and Git lineage; they were never published as releases.
