# Address 最小示例

任务：给“修复缺陷”父场中的接口契约分支分配动态地址。

已知场内必要轴：

```text
A 界定缺陷 → B 复现 → C 定位原因 → D 修复 → E 验证
```

`C3 接口契约`被打开为子场后，某条合法但尚未执行的路径可以登记为：

```text
F0:C3.2.3.3.1.3[◇]
```

其中 `[◇]` 只表示存在合法潜在路径。只有真实执行并通过审计后，相应结果才能登记为 `[+]`。如果当前契约禁止某项直接转换，登记的是 `[-]`；如果现有地址语法无法无失真表达某项任务相关差异，则登记为 `[∅]` 并触发改场、升场或外置判断。

可运行引擎的自检：

```bash
python plugins/rcf-address/skills/recursive-field-addressing/scripts/address_engine.py self-test
```
