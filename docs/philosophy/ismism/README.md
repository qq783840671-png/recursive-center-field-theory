# 主义主义（ISMism）四阶结构

## 编码方式

四位编码依次表示：

1. 场域论
2. 本体论
3. 认识论
4. 目的论

每一位数字表示该维度的基本结构：

- `1`：秩序
- `2`：冲突
- `3`：中心
- `4`：虚无

因此完整末级结构共有 `4 × 4 × 4 × 4 = 256` 种组合。例如，`1-1-1-1` 表示四个维度均由“秩序”主导；`4-4-4-4` 表示四个维度均落在“虚无”。

## 文件

- `主义主义4阶结构_256项.csv`：完整的 256 个四位编码，包含中英文名称、四轴含义、特征和相关视频等信息，适合筛选和检索。
- `ismism原始数据.json`：从“主义主义魔方”网页实际加载的数据文件原样保存；除 256 个四位编码外，还包括 4 个一阶、16 个二阶、64 个三阶条目及介绍信息。

## 数据来源与边界

- 数据来源：https://ismismtag.com/
- 未明子总纲：https://www.bilibili.com/video/BV1JT4y1K7dp/
- 抓取日期：2026-07-16

这些名称和说明是对“主义主义”框架的整理，不应直接视为学界通行的哲学分类或已经得到论证的结论。
