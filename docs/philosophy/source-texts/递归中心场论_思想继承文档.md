# 递归中心场论：思想继承文档

> 状态：唯一继承入口，更新于 2026-07-19。用途：为新的对话、Agent 或较长时间后的继续思考提供最小充分上下文。先读本文，不要先加载全部哲学长文。本文保存思想怎样走到当前位置、哪些概念已经相对稳定、哪些仍是假设、知识应写到哪里，以及下一步怎样继续。

## 一、当前 F0

继续发展并应用“递归中心场论”，同时避免把它退化为普通分类树、静态中心论，或取消定义域、现实修订能力与升场出口的自我豁免理论。

当前正式名称：

> **递归中心场论：相对中心、开放重构与无限寻址的场哲学**

核心传播句：

> **不是给世界一个永恒正确的中心，而是保留不断形成、检验和重建中心的能力。**

当前运行形式：

> **递归中心场动态模型以相对稳定的根目标为中心，在海量信息中生成场、形成 Focus、递归寻址、按偏序波前滚动执行，并根据结果持续重构。**

当前体系新增一个需要后续验证的操作中间层：**动态场寻址引擎（Address）**。它不是 Focus 内部的任意编号规则或纯交换协议，而是使原始信息、概念、关系、动作和剩余通过候选场形成、偏序／中心恢复、递归运动与吸收审计获得场相对身份、动态地址和潜在可执行位置。Address 已于 2026-07-19 建立为独立实验 Skill；它止于地址图和可执行地址视图，不执行外部领域任务，Focus 继续负责根目标、任务优先级、渗透策略和现实执行。其跨领域稳定性及相对于 token、词源、嵌入、分类或知识图谱方法的收益尚未得到实证。

当前动态模型有五个缺一不可的结构内核：**偏序、中心、场、递归展开／压缩、动力学**。这是本项目当前采用的构成性定义，不是已经由一次案例证明的跨任务普遍定律。地址生成必须区分全局展开与 Focus 渗透：前者不按传播权重筛选而统一推进合法前沿，后者在保持中心和偏序的前提下同时对多个合法节点不等深下潜、生成新地址并回写全景；建图和评分前仍必须先恢复依赖偏序并验证路径根地址。场形成、中心调整、Survey、Global Expansion、Focus、展开／压缩／重构、地址实现和 Execute 等地址生成运动都必须审计 `S_t=(M_t,Frontier_t,R_t,χ_t)`：现实／潜在地址、合法压缩前沿、未吸收结构差额及其地址关系必须同时保留，不能只展示已入图地址而默认场已闭合。

最新的运行纠错进一步规定：场形成必须服从 `需求及上级目的 → 场契约 → 完整有类型功能／关系图 → 经证据检验的必要偏序 → 最小充分承重中心 → 确认稳定 F0 → Global／Focus 地址运动 → Ready 偏序执行 → 剩余／闭合审计` 的前向构成顺序，不能先编答案或地址再倒推偏序。确认不是开始成场的许可，而是对已经通过图、偏序、中心最小性与剩余闸门的稳定产物加锁；未成场状态只能要求继续形成、人工校对、重构或升场，不能先显示未经验证的 F0 让用户替结构背书。活动剩余若要与暂时闭合并存，必须关联完整根路径和必要前序均合法、子场成场已验证、且有证据支持为 $d=1$ 或有限 $d=k$ 的 `[◇]` 前沿地址；`[◇,d=?]` 只是地址假设，不能支撑闭合。状态助手能拒绝缺证据、无根、缺前序和倒置结构，但不能独立证明领域语义为真，因此人工或工具证据核验仍不可取消。

最新默认首轮是在开放候选场完成偏序与中心验证、稳定为 F0 根层并由用户确认后，只形成 `F1=第一次 Global` 与 `F2=第一次 Focus`。每次展开的对象本身都是要重新成场和验证的递归子场，因此不再机械执行两次 Global＋两次 Focus；额外轮次只由剩余、未决前沿、显式深度或用户要求触发。数字递归节点分为 `hypothesized／forming／validated`：前两者只是 `[◇,d=?]` 地址假设，可保留在展开前沿或剩余账本，但不能支撑闭合、活动／执行路径或实现；只有第三者才是可用递归地址。每个已验证地址必须附带局部契约、完整关系图、必要偏序、最小充分中心、父场／返回接口、递归结构与剩余审计均通过的子场成场证明，以及证据绑定的内嵌可恢复状态快照、逻辑引用与可复算哈希；不能只检查证书字段或哈希格式。用户要求“理清／定位／分析”时在 F2 审计后交付；要求“做／执行／完成”时再由 F2 活动地址与必要前序诱导 `D_t／Ready_t` 并继续执行。

## 二、思想是怎样走到这里的

### 1. 从有限观测出发

最初问题来自雷达、多智能体和概率模型：主体只能通过量测、中介和模型接近世界，获得的是对状态的有限解释，而不是事物本身。概率分布既表达现实的不确定，也表达当前认识结构的边界。

这与康德的物自体、现象学的主体—世界关系、具身认识等问题发生会合，但并不是先从哲学史推演出来，而是从工程观测实践中独立产生。

### 2. 从确定性追求转向“中心—剩余—重构”

人和系统为了认识与行动，需要暂时确信和相对稳定的解释中心；任何中心又会遗漏、压缩或排除某些内容。这些内容作为剩余返回，迫使旧结构扩展、分裂或重构。

由此形成：

```text
形成中心
→ 维持相对稳定
→ 产生或显现剩余
→ 展开、压缩或重划边界
→ 重构新的相对中心
```

### 3. 从哲学运动转向结构方法

黑格尔的规定性否定、扬弃和历史沉淀提供了重要参照，但本理论不接受必然综合、必然进步、绝对精神或最终中心。它也与后黑格尔思想、现象学、结构主义、后结构主义、拉康、德里达、过程哲学和后基础主义发生交叉。

这些只是相邻谱系，不是本理论必须归顺的唯一来源。中国、印度等思想传统也不应被强行纳入一条以希腊—欧洲哲学为唯一中心的上升轴。

### 4. 找到“场内不可约中心”

在一个由需求、边界、方向、尺度和成功标准限定的场内，可以从多个具体实现中合并功能等价部分，再通过删除、替代、换序、压缩和空洞检验，寻找维持任务成立仍不可缺少的最小充分承重依赖子偏序。

中心不是最常出现、权重最大或最受关注的对象，而是当前场不能任意抽掉的承重功能位置及必要关系。

偏序先于 Focus 评分：它规定必要依赖、先后、可比与不可比关系及合法运动方向。没有 F0／本体根地址，或缺少必要前序的候选路径，不能靠热度、匹配度或成本获得合法性。

### 5. 形成递归地址

当前场中心用字母表示：

```text
F0: A → B → C → D → A′
```

具体实现、条件和被压缩子场用数字分支表示：

```text
A1、A2；B1、B2；C1、C2……
```

任何重要节点或关系都可以在需要时打开为子场；子场重新使用局部字母中心，并通过语义面包屑和压缩接口返回父场。返回 F0 Focus 视图时，内部层级压缩显示为根字母加不等长数字后缀，如 `A1.2、B1.1.2.3、C2.1`；同一根字母下可以同时有多条活动地址。地址是对象在特定场中的结构身份，不是脱离语境的永久编号。

### 6. 从静态结构进入动态模型

最初的结构拆解仍然容易在一次回答后收敛。进一步发现：使用者一开始往往不知道真正该关注什么，Focus 是在看到初步全景、获得证据和执行结果以后才逐渐形成的。

因此模型必须循环：

```text
Survey 形成初始合法前沿
→ 恢复偏序并形成暂定中心
→ 选择全局展开或 Focus 渗透
→ 全局展开统一推进合法前沿，或 Focus 同时生成多个不等深地址
→ ΔM_focus 回写全景并生成活动视图
→ 执行一个有限批次
→ 结果返回为证据、前沿或剩余
→ 更新 Focus 和场版本
```

### 7. 最新修正：闭合生产剩余

剩余不只是外部世界闯入场内的异常。场为了行动而追求闭合，必须规定中心、边界、合法地址、容差和压缩方式；这些操作本身会选择、合并和排除差异，使某些内容以“无法被当前结构无失真吸收的剩余”显现。

```text
追求相对闭合
→ 建立中心、边界和地址
→ 压缩或排除差异
→ 差异作为剩余返回
→ 暴露闭合限度
→ 迫使场重新敞开
```

场不一定凭空创造了现实对象，但共同生产了它作为“剩余”的结构身份。闭合与敞开因此属于同一个运动：场追求闭合的过程，可能制造迫使自身再次敞开的条件。

### 8. 最新动力学：父场闭合、子场运动与升场出口

每个有限场都围绕自身中心朝向相对稳定和局部闭合。父场为了处理未决项，会把内部节点展开为子场；子场又围绕自己的中心运动，并可能产生父场既有接口、地址和容差无法吸收的新差异。这些差异成为父场的内生剩余：

```text
父场趋向相对闭合
→ 为消除未决项而展开子场
→ 子场围绕自身中心趋向局部闭合
→ 子场生成新的对象、关系和可能性
→ 可兼容内容压缩回父场
→ 超出父场接口的内容成为剩余
→ 父场展开、升场、分裂或重构
→ 新父场再次趋向相对闭合
```

因此，局部运动指向闭合，递归整体却因子场持续生产剩余而保持开放。历史也不是沿一张永恒偏序图运动，而是形成版本化偏序：每一版场内依赖不可任意颠倒，跨版本运动则可能增加节点、改写关系和重建偏序。

本理论当前的生成规则在自身理论场内具有构成性的绝对地位；删除它们，当前理论就不再是同一个理论。但整个理论场具有有限定义域，可以整体压缩成更大认识场中的一个节点，在上级场中接受比较和修订。这一关系压缩为：

> **场内绝对，升场相对。**

当剩余直接触及生成规则时，不能把它强行降格为场内普通分支，而应把整个理论场升入更高场，或重构为新的理论版本。升场和重构就是当前中心面对自身剩余的出口。

终极真理也不因此被取消。它可以作为引导有限场持续形成局部真理的极限中心；但任何有限场都不能仅凭自身闭合宣称已经穷尽它。追求真理会打开此前被压缩的子场，并继续显现新的差异和剩余。

### 9. 最新运行修正：每次地址生成运动必须显示剩余、地址关系与前沿

一次“全局展开两次＋Focus 两次”的真实输出只展示了合法地址 $M_t$，没有显示运动产生的剩余和被压缩前沿，使动态模型在表现上退化成可完全闭合的静态分类树。后续讨论又确认：含糊任务解释、场形成、中心调整、Survey、展开／压缩／重构、地址实现和 Execute 都可能生产或吸收剩余。因此每次地址生成运动结束都必须执行剩余审计，状态至少为：

```text
S_t = (M_t, Frontier_t, R_t, χ_t)
```

`M_t` 是当前已经表示并带模态的合法地址图；`Frontier_t` 是场内合法、可继续展开但本轮暂时压缩或锁定的边界；`R_t` 是追求当前中心时由运动暴露、尚未被当前结构吸收或合法处置的结构差额；`χ_t` 记录剩余与现实地址、前沿、地址假设、负地址或无地址的关系、可达距离和吸收状态。未展开或被 Focus 降低运行优先级的合法节点不自动成为剩余，但一个尚未吸收的剩余可以暂时关联该潜在地址。

地址结果保留 `[+]` 已实现、`[◇]` 合法潜在、`[-]` 原则禁止和 `[∅]` 当前场不能独立生成／保证／合法表达四种模态；“尚未展开”不得标为 `[∅]`。剩余另保留未吸收、部分吸收、容忍、待人工、已吸收和禁止等吸收状态。复杂运动若声称没有新剩余，必须反查 F0 结果压平、下游优化与锁定必要前序契约的张力、以及当前场对外部结果的生成／保证缺口，并给出审计理由，但不能为了形式虚构剩余。锁定只禁止改写，不自动构成下游接口的保真证据。

> **剩余不是在场外静止等待的杂项，而是场追求闭合并发生运动时显现或生产出来的结构差额；它反过来使场保持敞开。**

### 10. 偏序波前执行与一句话闭环

> 状态：已写入 Focus Skill、协议和 schema 2.1 helper（2026-07-18）；尚未通过跨领域真实任务证明自动执行收益。

最终动态地址生成后，执行不按 `F0→F1→F2` 的来源顺序推进。`F0` 是根目标、硬约束与验收标准；`F1` 是 Global 快照，`F2` 是 Focus 快照；`A→B→C→D→E` 才表示当前版本的依赖偏序方向；数字后缀表示经过子场验证的递归地址与下潜深度，不自动等于多个待执行动作。

实际执行应从活动地址及其必要前序诱导可执行子偏序：

```text
D_t = Induce(Π_t, Active_t ∪ Pred_t)
Ready_t = {v ∈ D_t | v 的必要前序已满足，或由有效锁定／压缩接口担保}
```

先标记必要前序是已满足、锁定、压缩但契约有效、待执行还是阻塞，再只执行当前未解决的 `Ready_t` 动作节点。不可比较节点可以并行，汇合必须显式表达；资源排程顺序不能冒充因果偏序。schema 2.1 helper 已能从 Action 路径及必要前序重建 `D_t／Ready_t` 并阻止未稳定根目标契约直接执行，但具体工具调用仍由宿主 Agent 负责。

最终产品目标是“一句话调用后自动完成定场、中心调整、展开方式选择、动态地址生成、偏序执行和结果／剩余回写”，而不是要求用户逐阶段驱动。当前调用边界、建模协议、执行子图与 Ready 计算已经具备；状态 helper 可审计写回，但不替代宿主 Agent 的实际工具调用，也尚未证明跨任务稳定性，因此不能把目标产品形态写成已验证收益。

### 11. 场形成、剩余地址与人工校对

含糊问题不是一个已经稳定的场，而是场形成的输入。解释问题、调整根目标、生成候选中心、选择全景或 Focus、产生动态地址和执行本身，都是场运动与地址生成过程；每次运动都可能新增地址、吸收旧剩余、产生新剩余或暴露负地址／无地址结果。

地址状态与剩余吸收状态必须正交记录。`M_t` 与 `Frontier_t` 保存现实或潜在地址，`R_t` 保存尚未吸收的结构差额，`χ_t` 保存两者关系。剩余可关联已有现实地址、合法前沿、尚未验证的地址假设、负地址或无地址；可达距离区分 `realized／next／finite-deep／unknown／unreachable`。被后续展开或人工校对吸收的剩余不删除历史，而记录吸收运动、地址、证据和版本。

若用户命题内部同时要求同一对象在同一条件下“向左且向右”等不可共存结果，应产生 `[-]` 冲突地址并要求拆分、排序或重构；若结果超出当前场的合法表达、生成或保证能力，应记为 `[∅]` 并考虑升场或外部处理。只有会实质改变根目标、中心、边界、不可逆方向或高风险动作的歧义才触发人工校对；一般可逆细节由 Agent 在保留证据状态的前提下继续推进。执行稳定不等于剩余为空，而是所有阻塞执行的剩余已有合法处置。

### 12. 最新修正：模型暂稳、外部触发与版本地址

> 状态：用户在 2026-07-19 对话中明确提出的工作性修正；用于区分现实运动、理论模型和运行 Skill，尚不作为已经实证的自然规律。

现实场、理论模型和运行 Skill 不能混为一层。现实场可以持续运动，其不可逆后继关系表现为时间偏序；写在文本或状态中的理论模型则是一个暂稳的压缩快照，不被调用时不会自行展开。运行 Skill 的一次运动需要来自人或上一层过程的外部触发：人决定是否运动，已有剩余决定从哪里展开，偏序规定怎样展开才合法，场规定什么能够进入。对这个离散模型而言，一次合法展开是最小可观察运动；展开生成新地址，也可能显现供下一次运动定向的新剩余。

```text
暂稳模型版本
＋ 外部触发
＋ 与剩余相连的合法潜在地址
→ 执行一次展开
→ 生成新地址、地址变化和新剩余
→ 进入下一暂稳模型版本
```

外部输入不能仅凭被记录就推动模型。能够与当前剩余形成合法 `[◇]` 路径的输入，才可以触发场内展开；`[-]` 输入被当前原则禁止，与 F0 无关且在当前场没有地址的内容保持场外，均不改变当前模型。若一个 `[∅]` 差异实质影响 F0，它也不能伪装成普通向下展开，而应由上一层场决定校对、重构或升场。局部看是外力触发；放进更大的场以后，这个外力又可以成为上一层偏序中的合法前序。因此外部性是场相对的，不是绝对的。

模型版本必须区分当前活动地址、历史地址和退役地址。版本更新可以使大量子地址退出当前场，但不能把它们在旧版本中的存在抹除；对象失去当前场地址，也不等于对象本身消失，它仍可能在旧版本或更大的场中拥有地址。上一层地址变化可以向下级联，使许多子地址退役、迁移或重新生成；子地址变化则默认在局部消化，只有破坏上一层的不可约功能骨架、压缩接口或闭合能力时，才向上传播并迫使上一层更新。

公司只是这一规则的例子：部门和员工是某一版本承担功能的子地址，可以裁撤、合并、替换或新增；只要该公司场所要求的材料／资源进入、生产或价值转化、加工、交付与出售等不可约功能关系仍由新结构实现，公司父地址和谱系就可以保持不变。被裁员工退出当前公司版本，但其旧岗位痕迹仍保存在历史版本中，其本人也仍在更大的社会场中存在。这里的不变量是场相对的功能骨架，不是部门名称、人员数量或具体承担者。

## 三、当前最小概念集

| 概念 | 当前定义 |
|---|---|
| 场 | 由需求、主体、边界、方向、尺度、成功标准和历史共同限定的相对问题空间 |
| 偏序 | 当前场版本内规定必要依赖、先后、可比／不可比关系与合法运动方向的结构；反馈按版本展开 |
| 中心 | 当前场内维持任务闭环不可任意删除的最小充分承重依赖子偏序及必要接口 |
| 递归 | 节点和关系可按需展开为子场，完整子场又可压缩为父场接口 |
| 地址 | 对象在特定场、功能位置、实现路径和版本中的结构身份 |
| 动态场寻址引擎 Address | 使身份不足的输入通过候选场形成、偏序／中心恢复、递归运动、剩余吸收和审计获得场相对身份、动态地址与潜在可执行位置的有状态偏映射 |
| F0 | 当前运行的根目标、成功标准及不可被局部偷换的约束；场形成期可校准，执行稳定后须版本化修改 |
| 现实图 M_t | 当前已经实现并获得合法地址的结构，不是完成的万物地图 |
| 压缩前沿 Frontier_t | 场内合法且可继续展开，但本轮暂时压缩、锁定或降低运行优先级的地址集合 |
| 全局展开 | 不按传播权重筛选，把当前合法可展开中心节点或已有前沿统一推进一层，形成逐层增加的全景分辨率 |
| Focus q_t | 在认识过程中生成、保持中心并受当前偏序约束的多节点不等深渗透焦点 |
| 活动视图 V_t | 内部保存 F0 中心轴、根字母＋不等长数字后缀的活动地址、根路径及压缩／锁定接口；默认回复按需折叠 |
| Focus 增量 ΔM_focus | Focus 直接生成并回写全景的此前未显式枚举地址与关系 |
| Active Task | 当前 Focus 生成的有限执行批次 |
| 剩余 R_t | 由场的运动暴露或生产、对 F0 有影响但当前结构尚未吸收或合法处置的结构差额 |
| 剩余地址关系 χ_t | 剩余与现实地址、前沿地址、地址假设、负地址或无地址的关系，以及可达距离和吸收状态 |
| 模态 | `[+]` 已实现、`[◇]` 可吸收潜在、`[-]` 原则禁止、`[∅]` 当前场不能独立生成／保证／合法表达；不替代地址／前沿／剩余的结构分类 |
| 剩余审计 | 每次地址生成运动后对遗漏、压平、错误外置、前沿混淆、新剩余及旧剩余吸收进行的强制检查 |
| 压缩 | 折叠内部结构，同时保留契约、条件、不确定性和再次展开入口 |
| 重构 | 证据推翻原中心、方向或边界后，保留旧版本并建立新场结构 |
| 构成性中心 | 使当前场保持同一身份、在场内不可作为普通分支任意删除的生成规则或承重关系 |
| 升场 | 把完整场压缩为更大场中的节点，使场内绝对中心在上级场中成为可比较、可修正的局部中心 |
| 模型暂稳 | 理论模型作为一个压缩快照，在没有合法外部触发时保持当前结构；不等同于现实场停止运动 |
| 外部触发 | 相对于当前模型场，由人、执行者或上一层过程提供的运动启动条件；它只负责触发，不能绕过场内偏序和地址闸门 |
| 一次展开 | 从一个暂稳模型版本沿合法潜在地址打开一个下一层场或关系，并生成下一版本地址差分的最小可观察模型运动 |
| 地址生命周期 | 地址在不同版本中具有当前活动、历史保留或退役等状态；退役表示退出当前场，不表示对象或历史被删除 |
| 最小向上传播 | 子地址变化先在局部消化，只有破坏上一层不可约功能骨架、接口或闭合能力时才向上传播；上一层变化则可沿依赖关系向下级联 |

剩余至少区分：

- 外部遭遇：当前定义域没有预留的新对象、关系或事件；
- 闭合生产：当前边界、分类或合法地址规则排除了 F0 所需的差异；
- 子场内生：子场围绕自身中心运动时产生了父场接口无法吸收的新差异；
- 压缩返现：曾低于容差的内部差异积累后重新影响上层；
- 来源未知：现有证据不能判断来源。

## 四、当前动态闭环

```text
含糊任务进入场形成，生成暂定根目标 F0 与候选场契约
→ 必要时人工校对，直至执行稳定
→ M_t 持续更新
→ 恢复并验证当前版本依赖偏序 Π_t
→ 检验候选路径的 F0／本体根地址与必要前序
→ q_t 在认识中生成
→ 全局展开统一推进合法前沿，或 Focus 对多个合法节点不等深渗透
→ ΔM_focus 写回全景并形成 V_t
→ 报告 ΔM_global／ΔM_focus、压缩前沿及对应 ΔR
→ 从活动地址与必要前序诱导执行子偏序 D_t，并形成 Ready_t 波前
→ E_t 冻结本轮执行快照
→ O_t 返回结果与证据
→ 对每次地址生成运动执行剩余—地址、吸收与漂移审计
→ 更新 S_t=(M_t,Frontier_t,R_t,χ_t)、压缩接口、地址可达距离和吸收状态
→ 继续执行、重新 Focus 或重构
```

必须区分：

- F0 相对稳定，规定最终为什么做；
- Focus 可以变化，规定当前看哪里；
- Active Task 滚动生成，规定这一轮做什么。

只改变实现同一成功标准的观察路径是 Focus 变化；改变成功标准、主体或上级目的，需要形成新的 F0 版本。

## 五、不能退回的误解

1. 这不是普通树形分类。中心来自功能必要性检验，不是凭主题分组。
2. 这不是跨越所有定义域的终极中心论。中心在当前场内具有构成性，在升场以后又成为相对、可比较和可修正的局部中心。
3. 这不是完整万物地图。全景只是当前已探索和验证的结构。
4. 这不是所有尺度共享同一具体中心。重复的是生成语法，而不是中心内容。
5. 这不是字母加数字的形式游戏。没有场契约、必要性证据和父子接口的地址没有意义。
6. 地址越长不代表越重要，只表示当前观察得更深。
7. 不是所有差异都值得扩场。只有持续影响 F0、超过容差且不能局部吸收的差异才构成结构剩余。
8. 不是所有剩余都来自外部，也不是所有剩余都由场内部生产。
9. 递归潜在无界，但一次认识和执行必须有成本、边界与停止理由。
10. 哲学完整性不能代替技术证据，小规模实验也不能证明整套世界观。
11. 当前生成规则在本理论场内具有构成性的绝对地位；整个理论场在更大认识场中又只是可比较、可修正的局部中心，即“场内绝对、升场相对”。
12. 任何反例若都能被重新命名为普通剩余，理论就会形成自我豁免结构。真正触及生成规则的剩余必须能够使当前场整体升场，或修改中心和规则本身。
13. Focus 不是对任意类别重新加权。结构必要性、依赖先后、展开深度和任务／传播权重必须分开；后三者不能替代根地址与必要前序。
14. 根路径中被压缩的上层接口仍保留结构先行性、接口契约和重开地址。无根热点只能作为外部信息或剩余，不能进入合法 Focus。
15. 全局展开与 Focus 渗透不是同一运动。前者不按传播权重筛选合法前沿，后者的权重只决定合法地址本轮是否继续展开及展开多深。
16. Focus 不是只从已完成全景中静态挑选一条路径；它可同时生成同一根字母下的多条不等深地址，并把新增地址回写全景。
17. 已有地址、合法未展开前沿、无关场外信息和真正剩余必须分开；只有与 F0 相关且当前结构无法无失真容纳的内容才是真正剩余。
18. 每次运动不能只展示已入图地址 $M_t$；Global Expansion、Focus 与 Execute 后必须同时审计 $R_t$ 和 $Frontier_t$。
19. 剩余审计不等于强制剩余非空；复杂运动的空剩余结论需要理由，但不得为了形式虚构剩余。
20. `[∅]` 表示当前场不能独立生成、保证或合法表达的结果，不表示“尚未展开”；合法未展开节点是 `[◇]` 前沿。
21. `F0/F1/F2` 是默认首轮的有界成场顺序而不是现实执行队列：F0 是稳定根层，F1 是一次 Global，F2 是一次 Focus；实际动作从最终活动地址及必要前序诱导出的子偏序中按 Ready 波前执行。
22. 现实场持续运动，不等于理论模型会自行运动；运行 Skill 只有在获得合法外部触发时才执行一次展开。
23. 地址在新版本中退役，不等于对象消失或历史被删除；当前地址、历史地址和对象在更大场中的地址必须分开。
24. 父子地址的影响不是对称的，也不由节点数量决定；上一层变化可以向下级联，子地址只有突破上一层承重接口时才向上传播。

## 七、新对话怎样继承

新对话或 Agent 应先执行：

1. 首先读取本公开继承文档，并以[公开方法论入口](../../methodology/README.md)和[版本快照](../../../RELEASE_SNAPSHOT.md)恢复 F0、核心概念、当前版本和禁区；
2. 根据当前问题决定是否需要读取下级详细文档，不一次加载全部材料；
3. 区分用户是在补充定义、修正动力学、改变 F0、提出应用，还是给出反例；
4. 先说明新命题与当前模型是延伸、修正、冲突还是实例关系；
5. 用户明确要求“沉淀”或“更新”时，再写入相应本地文档；
6. 技术任务调用 `recursive-center-field-dynamics`，先从含糊输入形成开放候选场，经完整关系图、必要偏序、中心检验和剩余闸门稳定后才显示为候选 F0，请用户确认；确认以后默认依次运行 F1 一次 Global 与 F2 一次 Focus，再按任务意图交付或从活动地址与必要前序诱导 `D_t／Ready_t` 滚动执行。每个数字递归节点必须保存 `hypothesized／forming／validated` 状态；只有 `validated` 且内嵌状态快照可按规范复算哈希、结构可验证时，才能进入闭合、活动／执行路径或实现。记录 $\Delta M_{\mathrm{focus}}$ 及全景回写，并在每次地址生成运动后保存 `S_t=(M_t,Frontier_t,R_t,χ_t)`、地址可达距离、吸收状态与剩余驱动决策。“递归中心场动态模型”是正式名称，用户明确说“用 Focus 做一下”“这个任务用 Focus”“Focus 一下”等自然表达时，同样视为主动调用，不要求固定句式；
7. 不把未验证的普遍性、创新性或算法收益写成既定事实。
8. 接管时先向用户报告：继承入口、当前 F0、最新动力学、知识写入路由和未完成前沿；只有这五项一致，才算完成交接。

## 八、当前开放前沿

- 怎样从复杂数据中自动发现而不是人工指定暂定中心；
- 怎样在含糊自然语言中稳定形成可复现的暂定根目标，并判定何时必须人工校对；
- 怎样从异构对象和关系中自动恢复、验证依赖偏序，并稳定判断候选路径是否具有合法根地址；
- 不同主体在相同场契约下能否复现近似中心和地址；
- 怎样验证剩余的地址假设、估计其可达距离，并识别外部遭遇、闭合生产和压缩返现等来源；
- 怎样使不同执行者对同一运动复现近似的剩余审计，并区分真实空剩余、遗漏和错误外置；
- 怎样判断 `[∅]` 结果应保持无地址、通过外部系统处理，还是触发升场；
- 怎样量化 Focus 的收益、展开成本和停止条件；
- 怎样用真实任务检验“一次 Global＋一次 Focus”作为默认最低有界首轮的效果，并根据剩余密度、未决前沿、任务深度和成本安全地增加运动；
- 怎样稳定区分“理清／定位／分析”和“做／执行／完成”等任务意图，避免把分析误作行动授权或把行动停在模型；
- 怎样在真实工具链中验证由动态地址转换出的可执行子偏序、Ready 波前和显式汇合，并避免把资源排程、F 层或地址深度误作因果顺序；
- 动态场能否减少无关上下文、目标漂移和重复工具调用；
- 它与向量检索、RAG、知识图谱、层级规划和长期记忆怎样组合；
- 动态场寻址引擎的最小稳定状态、身份生成和运动操作能否在长期 Agent 任务／交接、科研知识与证据演化、多 Agent 协作三个场中复现；
- 同义改写下的地址稳定性、不同分析者的一致性、目标漂移变化与额外 token／建图成本怎样测量；
- 何种任务规模下，显式结构收益能够超过建图、路由和维护成本；
- 哲学体系怎样与黑格尔之后的现象学、结构主义、后结构主义、拉康、德里达及非欧洲传统进行更准确比较；
- 怎样允许真正外部改变本理论的地址语法，而不只是被重新收编。
- 怎样严格区分场内构成性中心、跨场终极中心和上级场中的相对中心；
- 什么证据表明剩余已经触及生成规则，必须升场，而不只是场内展开或参数修正；
- 终极真理作为极限中心时，怎样避免退化为不可检验的空洞指向。
