## 正式来源文本

`source-texts/` 保存体系形成过程中仍有独立阅读价值的正式文本：

- 递归场理论阶段总结
- 递归中心场论思想继承文档
- 场域相对的递归功能骨架方法论
- 从多智能体到科学的边界
- 开放场域中的递归骨架与生成时间
- AI 时代的科研祛魅、知识门槛与个人定位
- 递归中心场动态模型

`ismism/` 保存“主义主义”比较框架及其公开数据。它是局部比较工具，不预设为全人类哲学的统一等级表。

这些文本存在版本与表述差异时，以根级总纲和完整公开稿的现行定义为优先，旧文本保留其历史来源价值。
