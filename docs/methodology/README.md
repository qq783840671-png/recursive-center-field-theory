# 理论与方法论

本目录保存体系的根级公开文本。核心方法论只有一套：**递归中心场偏序动力模型**。定场、找中心、偏序检验、递归展开、压缩、剩余审计和版本回写都是这套方法的环节，不拆成彼此竞争的独立方法论。

## 建议顺序

1. [递归中心偏序动力场域论](递归中心偏序动力场域论.md)：体系根级总纲与地址登记入口。
2. [递归中心场论完整公开稿](递归中心场论_完整公开稿.md)：面对公共读者的完整论述。
3. [动态寻址](../dynamic-addressing/README.md)：由总模型展开出的关键中层方法。
4. [Focus 插件](../../plugins/rcf-focus/README.md)：当前主打应用。

## 最小运动轴

```text
A 形成场契约
→ B 恢复关系全景与候选中心
→ C 提取必要偏序并检验闭合条件
→ D 递归展开、动态寻址与不等深 Focus
→ E 沿合法前沿执行并审计证据与剩余
→ A′ 保存历史并形成下一版本
```

这里的“剩余”不是为了证明理论正确而人为补出的占位符。未决差异可以是可寻址潜在项，也可以暴露冲突、禁止或当前无地址；后两者会阻止场被伪装成稳定闭合。
