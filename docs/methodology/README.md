# 理论与方法论

本目录保存体系的根级公开文本。核心方法论只有一套：**递归中心场偏序动力模型**。定场、找中心、偏序检验、递归展开、压缩、剩余审计和版本回写都是这套方法的环节，不拆成彼此竞争的独立方法论。

## 建议顺序

1. [递归中心偏序动力场域论](递归中心偏序动力场域论.md)：体系根级总纲与地址登记入口。
2. [递归中心场论完整公开稿](递归中心场论_完整公开稿.md)：面对公共读者的完整论述。
3. [递归中心场偏序动力模型 v0.18](../spec/递归中心场偏序动力模型.md)：对构造型Focus、历史运行时、版本和寻址证据提供规范约束。
4. [多中心动态场域规范 v0.7](../spec/递归偏序多中心动态场域论.md)：区分完整场多中心、过程内单中心投影与多中心联合调度。
5. [动态寻址](../dynamic-addressing/README.md)：由总模型展开出的关键中层方法。
6. [Focus 插件](../../plugins/rcf-focus/README.md)：当前主打应用。

## 最小运动轴

```text
A 形成场契约
→ B 恢复关系全景、候选中心与完整场多中心地图
→ C 投影一个选中中心并提取必要偏序
→ D 在必要位置递归打开一层、动态寻址或执行
→ E 分别审计选中中心闭合与完整场闭合
→ A′ 保存历史并形成下一版本
```

这里的“剩余”不是独立物理力，也不是为了证明理论正确而补出的占位符。活动剩余使旧闭合证书失效并触发重审；是否以及怎样改变现实状态，仍取决于父契约、主体选择、合法前沿和具体中介。
