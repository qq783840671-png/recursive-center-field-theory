## 1. 体系定位

递归中心场域论研究的不是一个永恒不变的绝对中心，而是：一个相对场如何形成中心，如何依照偏序关系展开和压缩，如何在运动中产生剩余、生成地址，并在旧结构不足时重构自身。

核心传播句：

> 不是给世界一个永恒正确的中心，而是保留不断形成、检验和重建中心的能力。

三个不可删去的基本词：

- **递归**：潜在无限的展开、压缩与尺度切换。
- **中心**：当前尺度下不可随意抽离的方向、承重关系与功能骨架。
- **场**：中心能够成立的边界、关系、对象与运动范围。

偏序与动力不是附加修饰：

- **偏序**规定哪些关系必须先于另一些关系成立，以及运动能够沿什么方向发生。
- **动力**描述场在外部触发和内部剩余共同作用下，怎样由一个版本进入下一个版本。
- **域**是围绕当前根目标和理论谱系，已经获得合法地址的场、子场、关系、剩余与历史版本的总体。域不是绝对宇宙，也不是第五个理论层；它是当前整套递归场结构的版本化根容器。

删除“中心”，体系退化为无方向的递归分类；删除“递归”，体系成为静态中心场；删除“场”，相对中心会被误读为绝对中心；删除“偏序”，不同层级会再次被压平；删除“动力”，地址只剩静态目录。

## 2. 根偏序与四层框架

本体系当前的根生成链为：

```text
A 哲学思想
→ B 方法论
→ C 递归中心场偏序动力模型
→ D 应用工具
→ A′ 经应用、审计和剩余回流后的下一版本体系
```

这条链表达生成依赖，不表达高低贵贱，也不等于四类内容的平面并列。

### A. 哲学思想

回答“世界和认识为什么可以被理解为相对中心、开放场与持续重构的运动”。当前承重点包括：

- `F0:A1` 相对中心：具体中心可能失效，但形成中心的能力可以保留。
- `F0:A2` 场—中心共构：场使中心可判定，中心使场获得内部结构。
- `F0:A3` 剩余与敞开：场追求相对闭合的运动会生产自身无法完全吸收的剩余，剩余反过来迫使场敞开。
- `F0:A4` 递归重构：旧场不必消失，而可被压缩进新场并获得新的身份。
- `F0:A5` 相对稳定：事物可以在某一尺度上稳定，同时在更小或更大的尺度上持续运动。
- `F0:A6` 可重建的确信：相信的不是当前答案永远正确，而是旧中心失效后仍可重建足以支持认识和行动的中心。
- `F0:A7` 思想继承与差异：与黑格尔、后基础主义、结构主义/后结构主义、解构、拉康及相关思想进行结构层比较，而非只做关键词归类。此地址待专题展开。
- `F0:A8` AI 加速与地址危机：信息和技术变化加快时，主体更容易失去可行动的相对中心；理论的回应不是恢复永恒中心，而是恢复定场、检验与重建中心的能力。
- `F0:A9` 历史与伦理回望：场的偏序运动不会自动等于进步。借用本雅明“历史天使”的警示，体系必须保留被新版本排除的对象、断裂与代价，不能用地址增长掩盖历史创伤。

### B. 方法论

把哲学结构转化为可执行的认识与组织过程：

- `F0:B1` 定场：明确当前需求、对象、边界、尺度和停止条件。
- `F0:B2` 找中心：从功能闭环中识别不可约的承重关系，而非凭表面类别指定中心。
- `F0:B3` 偏序检验：用删除、替代、换序和压缩检验生成依赖。
- `F0:B4` 递归展开：节点可向内形成子场，完整场可向上压缩为更大场中的节点。
- `F0:B5` Focus：依据当前焦点选择性加深合法地址，其余必要结构保持为压缩接口；Focus 不是权重排序，而是打开一个有边界、有局部 F0、有返回路径的子场。
- `F0:B6` 剩余审计：记录哪些内容已吸收、可展开、被禁止或在当前场无地址。
- `F0:B7` 停止：达到当前目标所需的充分结构后停止，不把潜在无限误写成一次性穷尽。
- `F0:B8` 执行与回写：从活动地址及其必要前驱诱导可执行子偏序，只有经执行和审计的结果才能成为现实地址。
- `F0:B9` 版本与失效传播：区分运行记录、全景地图和场闭合版本；局部变化先保持局部，只有破坏上级承重接口时才向上传播。

方法论的完整工作协议不是一棵预先分类好的树，而是：`Γ 定场 → G 恢复关系 → Π 提取必要偏序 → 𝒦 检验候选中心 → 递归寻址 → Global/Focus 运动 → D/Ready 执行 → χ 剩余审计 → 版本回写或重构`。

### C. 递归中心场偏序动力模型

把方法论表达为具有状态、地址和运动规则的显式模型：

- `F0:C1` 场状态：记录当前模型、展开前沿、剩余与闭合状态。
- `F0:C2` 场相对递归地址生成模型：规定对象如何依据所属场、中心、上级偏序、递归路径、场版本和模态状态获得候选地址，并检验其合法性；地址的后续迁移、退役和版本操作由 `C4` 负责。
- `F0:C3` 偏序运动：父级变化可向下重排大量子地址；子级变化通常保持局部，只有破坏父级承重接口时才向上传导。
- `F0:C4` 地址生命周期与操作：记录地址的保留、展开、压缩、迁移、分裂、合并、新生、退役、外置和禁止，但不负责决定一个初始地址为何合法。
- `F0:C5` 剩余驱动：剩余给出展开方向，但不会自动执行更新；理论模型需要人或更上级场提供触发力。
- `F0:C6` 稳态与敞开：模型在未触发时是暂稳态；合法潜在地址允许继续展开，负地址和无地址要求阻断、外置或重划场界。
- `F0:C7` 历史与滞回：当前地址可失效，但对象及其历史痕迹不因此消失；历史版本不可被静默覆盖。
- `F0:C8` Focus 状态模型：记录一次选择性穿透所形成的局部场视图、活动路径、压缩接口、前沿、剩余、版本与返回路径；它是全局场状态的有界投影，不是独立于场的注意力权重。

### D. 应用工具

把模型转化为可调用、可监督的工具：

- `F0:D1` Focus Skill：执行定场、全局展开、Focus 穿透、地址生成、剩余审计、偏序执行与结果审计。
- `F0:D2` 体系维护：将后续对话中的有效输入路由到本总纲的合法地址，并记录版本差分。
- `F0:D3` AI 信息处理：上下文组织、跨会话记忆、结构化检索、RAG/GraphRAG 接口和智能体编排。当前属于应用方向与待验证假设。
- `F0:D4` 显式策略结构：将强化学习或复杂决策中的角色、功能和传递链显式化。当前属于研究假设，不宣称已优于既有方法。
- `F0:D5` 公共传播与复用：公开文档、示例和 Skill。传播不能反向篡改 A—C 的理论不变量。
- `F0:D6` 可计算地址模块：把 `C2/C4/C8` 的规范转换为可由计算机生成、登记、查询和审计的地址。当前只登记工程接口；具体实现由独立任务维护，验收前保持 `[◇]`。

A—C 构成理论内核；D 使体系获得可执行和可检验的应用闭环。删除 D 不会使哲学命题消失，但会使当前项目失去工具化闭环。

## 3. 理论不变量

以下内容是当前版本的承重原则。除非明确启动根场重构，否则不得因文案、传播或局部应用需要而静默修改：

1. 场与中心相互规定，不存在脱离场的绝对中心。
2. 中心是不可约的功能关系和生成依赖，不是最醒目的对象，也不是权重最高的标签。
3. 偏序先于权重。权重只能在合法关系中表达影响大小，不能代替生成次序和层级关系。
4. 展开产生新地址，压缩保留被压缩结构的可恢复关系；压缩不等于删除。
5. 同一对象可在不同场、不同版本中拥有不同地址。
6. 对象失去当前场地址，不等于对象从更大的现实或历史场中消失。
7. 父地址改变可以级联改变子地址；子地址只有触及父级承重接口时才改变父场身份。
8. 场在运动中产生剩余，剩余必须被标记，不能靠措辞消失。
9. 具体展开具有历史偶然性，展开所受的依赖约束具有条件必然性。
10. 每个场都保留向内展开、向外升场或重构边界的出口。

## 4. 地址体系

### 4.1 地址的组成

完整地址至少表达：

```text
域版本 + 持久 field_id + 上级绑定/返回接口 + 局部中心节点 + 递归路径 + 模态状态
```

工作表示例：

```text
v0.3::F0:C2.1.3 [◇]
```

其中：

- `F0` 表示当前被打开、当前受到关注的局部根场；打开下一层时，下一层在自己的视图中成为新的局部 `F0`。
- `F1—F4` 仅保留默认两次 Global 与两次 Focus 的运动来源快照，不是子场编号、地址前缀或执行层级。
- 字母节点表示当前场的不可约中心轴。
- 数字后缀表示节点内部递归展开出的分支。
- 持久 `field_id` 与上级绑定保证子场身份不因视图切换而丢失；返回上一级时，局部字母中心压缩为上级字母节点后的数字路径。
- 地址表示位置，根路径与偏序链表示可达性，模态表示该地址与当前场的关系。

### 4.2 场相对递归地址生成模型

该模型位于当前理论场的 `F0:C2`。对它执行 Focus、把它打开为当前研究对象时，内部视图重新以局部 `F0` 表示；返回理论总览时再压缩回 `C2`：

```text
父场视图：F0:C2
子场视图：field_id=CF-F0-C2-v1；local F0:A→B→C→D→E→F→A′
返回父场：F0:C2.1.3…
```

它不是给对象粘贴一个外部分类标签，而是让对象进入一个已经定界的场，并由场、中心、偏序和递归路径共同生成其位置。

地址生成的当前不可约中心轴为：

```text
A 确定所属场、根目标与场版本
→ B 找到场的中心轴及父级偏序位置
→ C 确定对象相对于中心的功能关系
→ D 沿合法关系递归展开到足以区分对象的深度
→ E 标记对象的模态状态和生命周期状态
→ F 进行合法性、唯一性、重复性与历史连续性审计
→ A′ 生成该版本中的场相对地址
```

每个节点都可以继续递归展开。例如：

- `A1` 所属域版本；`A2` 当前场边界；`A3` 当前根目标。
- `B1` 直接父地址；`B2` 前置依赖；`B3` 不可越级的中介。
- `C1` 承重功能；`C2` 输入输出关系；`C3` 与同层对象的区别。
- `D1` 必要分辨深度；`D2` Focus 深度；`D3` 当前停止条件。
- `E1` 现实地址；`E2` 潜在地址；`E3` 负地址；`E4` 无地址。
- `F1` 冲突检查；`F2` 等价地址合并；`F3` 历史谱系检查；`F4` 地址差分登记。

一条具体的工作地址可以表示为：

```text
v0.3::field=CF-F0-C2-v1::F0:A2→B1→C1→D2→E2→F3 [◇]
parent_return=F0:C2.2.1.1.2.2.3
```

地址生成必须满足以下约束：

1. **先定场，后寻址**：没有场边界，就不存在该场中的合法地址。
2. **先偏序，后编号**：编号只能记录已经成立的关系，不能替代父级依赖和功能位置。
3. **先功能关系，后表面名称**：同名对象在不同功能场中可以获得不同地址；异名对象若承担等价功能，可以进入同一中心节点下的不同分支。
4. **逐级展开，不得越级挂载**：若对象与目标之间缺少必要中介，应补出中介场或标记为无地址，不能用一条假想直连掩盖关系缺口。
5. **展开到够用为止**：地址理论上可无限增长，实际深度由当前场的目标、区分需要和停止条件决定。
6. **生成后必须审计**：未经过合法性与历史连续性检查的结果只是候选地址，不能登记为 `[+]`。

四个相关部分必须保持区别：

- 方法论层 `F0:B` 说明使用者怎样定场、找中心和检验偏序。
- 地址生成模型 `F0:C2` 说明对象怎样获得合法地址。
- 地址注册表保存已经生成的地址、状态和历史。
- 动力模型其余部分说明地址怎样随场的运动而保留、变化或退役。

### 4.3 模态状态

- `[+]` 已在当前版本实现并经执行—审计确认的现实地址。
- `[◇]` 与当前场规则相容、尚未实现的潜在地址。
- `[-]` 被当前场承重原则禁止的负地址。
- `[∅]` 当前场无法生成或表达的无地址内容。

`[-]` 或 `[∅]` 不自动证明整个场错误。只有当该内容属于根目标要求必须吸收的对象时，它们才构成场界错误或重构信号；否则应阻断或外置，不能强行收入当前场。

### 4.4 地址生命周期

地址必须区分：

- **现行地址**：当前版本仍承担功能的位置。
- **历史地址**：曾经有效，现已被新版本替代的位置。
- **退役地址**：退出当前场，但仍保留来源、去向和退役原因的位置。

任何对象都不能被“无痕删除”。它可以离开当前场，但历史登记必须保留。

### 4.5 版本与地址差分

每次被体系正式吸收的更新都必须推进**运行历史版本**并生成可审计记录，但不自动推进整个域的语义版本。只有全景、场契约、关系/偏序、模态、剩余、Focus 路径或前沿发生变化时，才推进地图版本；只有受影响场重新通过闭合审计时，才推进该场的闭合版本；只有根接口或构成身份改变时，才推进根域语义版本。即使结构地址不变，也必须明确登记为“保留”或“内容替换”，不得静默覆盖。

允许的差分操作：

```text
retain      保留地址
replace     地址不变、内容或定义更新
expand      从节点展开子场
compress    将完整场压缩为上级节点
move        在同一域内迁址
split       一个地址分裂为多个地址
merge       多个等价地址合并
birth       生成新地址
retire      从当前版本退役
externalize 移出当前场、保留外部引用
prohibit    判定为当前场负地址
```

因此，“每次更新都要有地址变化”在本体系中的严格含义是：**运行记录必然变化，受影响对象必然产生可审计的差分；但地图版本、场闭合版本、根域语义版本和对象结构位置只在各自条件满足时变化。**

### 4.6 Focus 状态与可计算地址模块接口

Focus 既是一种选择性穿透运动，也会形成一个可保存、可返回的局部状态。当前将该状态记为：

```text
Q_t = <q_t, local_F0, Γ_t^q, K_t^q, Π_t^q,
       P_t^active, I_t^compressed,
       ExpansionFrontier_t^q, ActionFrontier_t^q,
       R_t^q, v_t^map, parent_return>
```

其中：

- `q_t` 是本次聚焦条件，不等于根目标；它只规定当前要穿透哪一部分。
- `local_F0` 是被打开子场在当前视图中的局部根，`parent_return` 保存返回上一层的合法路径。
- `Γ_t^q / K_t^q / Π_t^q` 分别保存局部场契约、经检验的局部中心和必要偏序。
- `P_t^active` 是已显现的活动路径；`I_t^compressed` 是未展开但必须保真的压缩接口。
- 两类 `Frontier` 分别记录仍可展开的结构和已经具备前驱条件的行动；二者不得混用。
- `R_t^q` 只记录影响当前局部 F0 且尚未被吸收的真正剩余；普通未展开内容仍属于前沿。
- `v_t^map` 使同一焦点在场运动前后可以做地址差分，不能把一次视图误当成永久结构。

因此，**Focus 状态不是一个关键词集合、注意力分数或孤立地址，而是全局场状态在当前焦点下形成的有界、版本化、可回返投影。** Focus 不得凭权重创造地址，也不得越过必要前驱；只有合法展开产生的新路径才能写回全景。

可计算地址模块位于应用层 `F0:D6`，其规范依赖链为：

```text
C2 地址生成与合法化
→ C4 地址生命周期和差分操作
→ C8 Focus 状态及活动路径
→ D6 可计算地址模块
→ D1 Focus Skill 或其他调用工具
```

`D6` 的最小接口暂定为：

- **输入**：场契约、完整关系图、必要偏序、经检验中心、当前 Focus 状态、场/地图版本和剩余账本。
- **输出**：候选地址、合法地址、模态状态、完整根路径、父场返回接口、地址差分及未吸收剩余。
- **约束**：编号不得代替关系；权重不得制造地址；不得越级挂载；不得覆盖历史地址；未经执行—审计不得标记为 `[+]`。

这里登记的是工程位置和规范边界，不是对具体实现的预先认定。由其他任务形成的地址模块只有在接口、合法性测试和版本差分通过审计后，才能从 `[◇]` 转为当前域中的现实地址。

## 5. 动力模型

递归中心场偏序动力模型的最小运动闭环为：

```text
暂稳态场
→ 外部触发输入
→ 输入与现有地址发生关系
→ 形成或显现剩余
→ 偏序与承重原则进行合法性检验
→ 执行一次最小合法展开/压缩/迁址/重构
→ 生成新地址与新版本
→ 审计残余和闭合状态
→ 进入下一暂稳态或保持敞开
```

动力来源必须分开：

- **运动产生剩余**：场的运行和展开会显现旧结构无法完全覆盖的内容。
- **剩余提供方向**：它指出哪里可能需要展开、升场或重构。
- **外部触发提供推力**：在 Skill 或文本模型中，必须由人或更上级场发出合法更新指令。
- **偏序提供约束**：输入只有获得潜在地址，或合法触发父场重构，才能改变当前体系。

胡言乱语、无关信息或违反承重原则的输入，不能因为被记录就自动推动体系运动。

## 6. 体系维护协议

以后所有准备吸收进本体系的对话、文档或新设想，按以下顺序处理：

```text
1. 接收原始输入，但不立即改写理论
2. 判断它属于 A、B、C、D，还是跨层机制
3. 定位现有地址与父级偏序
4. 判断：重复、细化、展开、冲突、负地址或无地址
5. 选择最小合法操作
6. 只传播到真正受影响的父/子地址
7. 更新当前版本和地址差分
8. 保留被替换内容的历史地址
9. 审计新产生的剩余
10. 给出暂稳态或敞开状态
```

输入的默认去向：

- 能解释哲学前提的内容进入 `F0:A`。
- 能规定如何定场、找中心、展开和审计的内容进入 `F0:B`。
- 能规定状态、地址、偏序和动力过程的内容进入 `F0:C`。
- 能被执行、调用、验证或复用的实现进入 `F0:D`。
- 同时影响多个层级的内容先进入跨层登记，不得压进任一平面分类。

## 7. 跨层登记机制

以下机制横穿 A—D，不另立为第五层：

1. **术语与不变量登记**：防止“中心、场、域、偏序、剩余、地址”等术语漂移。
2. **地址注册表**：记录当前、潜在、禁止、无地址及历史地址。
3. **版本谱系**：记录每次运动前后哪些结构保留、改变或退役。
4. **剩余账本**：记录未吸收内容、可达距离、吸收历史和停止位置。
5. **证据状态**：区分用户明确命题、理论推论、工作假设和已验证结果。
6. **监督与写入路由**：保证局部 Focus 或传播目标不能越权修改根级不变量。

## 9. 论断边界

### 稳定定义

- 正式名称、简称和动力模型名称。
- A—D 根偏序及场—中心—递归—偏序—动力—域的基本关系。
- 版本化地址、历史保留和剩余审计原则。
- Focus Skill 在体系中的应用层位置。

### 工作假设

- 显式地址和偏序结构可能减少长上下文中的概念漂移。
- 该结构可能改善大规模知识组织、跨会话记忆、检索和智能体协作的可解释性。
- 显式策略结构可能缩小无方向的组合搜索空间，或帮助诊断强化学习中的发散。

### 开放问题

- 怎样形式化“不可约中心”的检验强度与等价中心。
- 怎样衡量场边界、剩余可达距离和地址更新成本。
- 显式结构在何种规模下能够抵消其额外建模开销。
- 怎样通过对照实验区分真实的漂移抑制与事后解释。
- 怎样与知识图谱、层级任务网络、因果模型、GraphRAG、程序化提示和结构化记忆做结构层而非关键词层的比较。
