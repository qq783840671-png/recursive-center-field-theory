# 与相邻理论、方法和工具的对照

本项目通过结构差异说明自身位置，不用“别人都没有、只有本理论有”的宣传句替代证据。

## 比较原则

1. 先比较对方真正解决的问题，不把单一实现代表整个领域。
2. 区分已有能力、候选组合差异和尚未验证的性能假设。
3. 只有公开实验支持后，才把“可能更好”改写成经验结论。
4. 每项优势同时写明失败条件和额外维护成本。

## 当前候选差异

| 相邻方向 | 已有强项 | 本体系尝试增加的结构 | 当前限制 |
|---|---|---|---|
| ReAct、Tree of Thoughts | 推理与行动交替、候选分支搜索 | 场契约、候选承重中心、必要前驱、版本化剩余 | 结构提取成本更高，收益未普遍验证 |
| HTN、DAG 工作流、Behavior Tree | 层级分解、前驱、执行控制 | 让任务场和中心候选也能被证据重建，并保存可重开压缩 | 不能替代成熟调度器和领域模型 |
| LangGraph、AutoGen 等编排框架 | 多 Agent 状态与流程编排 | 任务相对的偏序合法门、动态地址和剩余回写协议 | 当前只是可组合结构层，不是完整平台 |
| 向量 RAG、GraphRAG | 语义召回、实体关系与主题群落 | 区分“表面相关”和“当前任务不可删除”，保存前驱、闭合和版本 | 仍需依赖底层召回，显式建模有成本 |
| RDF、属性图、知识图谱 | 通用多关系表达和查询 | 为场相对地址、压缩、重开、审计规定统一运动语义 | 不宣称图表达能力超过通用图系统 |
| Agent memory、Mem0、Letta/LangMem 类系统 | 跨会话事实、事件和记忆管理 | 把中心偏序、合法前沿、过期状态与剩余一起恢复 | 尚缺统一公开基准结果 |
| Options、层级强化学习、动作屏蔽 | 时间抽象、层级策略、非法动作控制 | 用可审计的场与偏序作为显式策略外结构先验 | 错误中心可能排除有效探索 |
