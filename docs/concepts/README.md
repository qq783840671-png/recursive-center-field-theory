# 概念沉淀

本目录保存从长对话中提炼、经过边界修订后仍具有独立阅读价值的概念文本。它们用于扩展解释、提出比较和保存开放问题，不高于根级总纲与专门规范。

- [递归多中心结构维度展开与数学工具边界](递归多中心结构维度展开与数学工具边界.md)：工程拟合身份、尺度／分辨率、傅里叶、勒贝格积分、分形、信息论与相关工具的责任边界。
- [递归场视角下的大模型研究展开与分辨率困境](递归场视角下的大模型研究展开与分辨率困境.md)：AI／LLM 的选择性展开、上下文迷失、分层回卷和待验证性能假说。
- [回溯性建构、终态信念与概率地址](回溯性建构、终态信念与概率地址.md)：部分观测概率、反向规划、事后重构、终态信念与退出审计。

这些文本不把模型拟合成功写成对象本体证明，也不由概率描述推出全局决定论，不把回溯规划等同于物理逆因果。
