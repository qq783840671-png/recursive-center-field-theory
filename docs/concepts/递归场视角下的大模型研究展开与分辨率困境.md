# 递归场视角下的大模型研究展开与分辨率困境

> 状态：内部概念沉淀；递归场栈与分层回卷摘要已进入动力母稿v0.14，尚未进入AI系统实现  
> 来源：2026-07-30连续对话  
> 适用范围：AI辅助科研、研究Agent、检索增强、搜索／推理预算、动态展开与停止  
> 证据边界：用户理论解释、技术事实、模型形式化和待验证假说分别标注；本文不把“AI没有认知”写成已验证事实

## 一、耐久中心

用户提出：人类研究未知领域时，并不是从零穷尽全部知识维度，而是先恢复父场要求，从论文、公式、代码和前人成果中调用已经相对闭合的接口；只有阻断当前研究闭合的场才继续打开。当前大模型或其外围Agent若没有显式任务分辨率、证据标准和停止契约，就容易依靠语言相关性、搜索评分或算力预算扩张候选，而不知道“当前任务究竟需要多细”。

因此候选问题不是“大模型参数空间维数太少”，而是：

```text
模型缺少或没有被显式提供
任务场的闭合契约
+ 尺度／误差／可靠度
+ 中心身份和必要性
+ 证据与现实反馈
+ 展开成本
+ 停止和重开条件
```

Focus的AI候选作用是：在父场契约下选择一个当前中心，先复用已有闭合接口，只对活动剩余作有限深度展开，审计后再决定停止、重开、切换中心或提高分辨率。

这里的“场”是任务工程模型，不是被研究对象或AI内部真实结构的同义词。它是否有用取决于能否减少无效展开、提高证据质量并保持任务正确率，而不是取决于它是否被解释成世界本体。

## 二、人类研究的递归场解释

### 2.1 不是从零造轮子

一个研究任务可表示为：

```text
形成问题场
→ 检索前人成果
→ 把成熟理论／公式／代码压缩为可审计接口
→ 找到尚未闭合的必要位置
→ 只打开这些位置
→ 实验或推导返回证据
→ 在当前精度下形成相对闭合
```

论文检索和知识复用不是任务外的辅助动作，而是从公共知识场调用已经闭合的子场接口。接口必须保留来源、适用条件、误差、版本和重开条件；“前人做过”不自动保证当前任务可以直接复用。

状态：**用户明确的研究方法解释**；“公共知识场接口”是**模型形式化**。

### 2.2 高精度要求会恢复更多必要条件

当实验从粗略可行提高到更严格精度时，原来可压缩的温度、湿度、数据分布、传感器误差或算法交互可能重新成为活动中心；已有中心也可能向更深层展开。宏观任务投影近似不变，并不表示内部有效场没有扩大。

状态：**用户明确**；详细分辨率契约见`20_知识沉淀/概念/递归多中心结构维度展开与数学工具边界.md`第十三节。

## 三、必须区分的四种“维度”

“AI维度太低”若不拆分会形成误导。至少区分：

1. **表示维度**：神经网络隐藏向量和参数空间可以非常高维；
2. **模态维度**：文本、图像、声音、视频、传感器和动作等输入／输出通道；
3. **任务结构维度**：中心、偏序、因果、约束、证据、资源、风险和闭合接口；
4. **搜索维度**：候选分支数、展开深度、工具选择和回溯空间。

标准Transformer在固定层数和隐藏维度中处理token序列，并不在推理时字面枚举“世界的所有维度”。其原始架构事实可见[Vaswani等人（2017）](https://doi.org/10.48550/arXiv.1706.03762)。

更准确的用户命题是：

> 语言模型即使具有高维内部表示，也未必显式拥有当前任务所需的中心身份、分辨率、证据义务和闭合地址。

多模态系统增加观察通道，但“增加模态”不自动产生任务结构、因果理解或正确停止条件。

状态：首句修正为**技术事实边界**；上述命题为**用户方向经模型澄清后的工作假说**。

## 四、为什么缺少尺子会造成组合爆炸

若每个活动节点平均产生`b`个候选，展开深度为`d`，完整搜索节点数近似：

\[
N(d)
=
1+b+\cdots+b^d
=
\frac{b^{d+1}-1}{b-1}.
\]

问题表现为组合爆炸，而不必解释成数学意义上的“进入无限维空间”。当系统没有闭合阈值、相关性边界或有效评估器时，它可能：

- 打开与父任务无关的场；
- 在相关场中使用远高于任务需要的精度；
- 重复打开已有成熟接口；
- 生成大量语言上合理但不可验证的分支；
- 在缺少现实反馈时把继续生成误当成继续认识。

海岸线类比表示：

\[
\delta\downarrow
\quad\Longrightarrow\quad
\text{可见细节和路径成本通常上升}.
\]

但AI训练或推理“不收敛”还可能来自目标冲突、优化不稳定、数据噪声、评估器错误、环境非平稳或搜索策略失败，不能全部归因于误入无限细分辨率。

## 五、大模型常见机制不能统称为“裁剪”

| 机制 | 实际作用 | 与Focus的关系 |
|---|---|---|
| 梯度裁剪 | 限制训练梯度范数，缓解梯度爆炸 | 训练稳定机制，不决定任务场展开 |
| 模型剪枝 | 删除或稀疏化权重、连接、头或模块 | 压缩模型结构，不等于搜索分支裁剪 |
| 搜索剪枝／波束限制 | 删除低评分候选路径 | 可限制横向分支，但依赖评分器 |
| 迭代加深 | 反复执行深度受限搜索并逐步提高上限 | 接近“每轮只多打开一层” |
| 提前停止／动态停机 | 达到验证阈值或学习到停机概率后停止 | 接近相对闭合停止条件 |
| 检索增强 | 调用外部文献或数据库，而非仅靠参数记忆 | 接近复用已经闭合的知识接口 |
| 工具调用／实验反馈 | 从代码、仪器、数据库和环境获得证据 | 为语言场增加现实校验接口 |

梯度裁剪针对梯度爆炸，参见[Pascanu、Mikolov与Bengio（2013）](https://proceedings.mlr.press/v28/pascanu13.html)；模型剪枝和量化的代表性工作见[Han、Mao与Dally（2015）](https://doi.org/10.48550/arXiv.1510.00149)。把二者写成“逐层限制推理展开”属于技术误读。

“先限定深度运行，再提高一层重新运行”更接近[Korf（1985）的迭代加深搜索](https://doi.org/10.1016/0004-3702(85)90084-0)。动态计算深度和停机可参考[Adaptive Computation Time](https://arxiv.org/abs/1603.08983)及带逐位置动态停机的[Universal Transformer](https://arxiv.org/abs/1807.03819)。

## 六、研究型AI的候选场契约

研究任务交给AI前，父场至少应提供：

\[
\Gamma_{AI}
=
\langle
Q,B,\delta,\epsilon,\tau,
\mathcal E,\mathcal T,K
\rangle,
\]

其中：

- `Q`：要返回的任务对象和输出类型；
- `B`：适用域、禁止域和边界；
- `\delta`：最小有效分辨率；
- `\epsilon`：允许误差；
- `\tau`：可靠度或条件覆盖要求；
- `\mathcal E`：证据和验收规则；
- `\mathcal T`：允许调用的检索、代码、仪器和数据工具；
- `K`：时间、token、计算、实验和风险预算。

没有`\mathcal E`，语言上的自洽可能冒充任务闭合；没有`\delta、\epsilon、\tau`，系统不知道何时应继续下潜；没有`B`，系统可能把邻近但无关的场纳入任务。

## 七、Focus型AI循环

候选运行循环为：

```text
读取父场契约
→ 恢复候选中心和必要偏序
→ 检索已有闭合接口
→ 选择一个Focus中心
→ 本轮最多增加一个受控展开层或一组必要平级位置
→ 调用工具／实验取得证据
→ 审计闭合残差、硬门和误差预算
→ 停止、重开、切换中心或提高分辨率
```

可写成：

\[
S_{t+1}
=
\operatorname{Audit}_{\Gamma_{AI}}
\left(
\operatorname{Expand}_{\leq h_t}
\left(
\operatorname{Focus}(S_t)
\right)
\right).
\]

其中`h_t`是本轮允许增加的深度，不必永远等于一。只有在：

\[
\operatorname{Closure}_{\Gamma_{AI}}(S_t)=1
\]

且所有硬门、证据义务和未建模剩余均进入允许边界时停止。

这与现有的树搜索、反思、回溯和候选自评估具有局部相似。例如[Tree of Thoughts](https://proceedings.neurips.cc/paper_files/paper/2023/hash/271db9922b8d1f4dd7aaef84ed5ac703-Abstract.html)允许探索多个推理路径、评估选择并回溯；但其“thought”节点没有自动获得本理论中的中心身份、闭合义务和跨场地址。

### 7.1 仅有监视器不足以完成尺度回退

一个监视器可以发现token、时间、工具调用或重复次数超标，却未必知道系统已经进入哪个子场、当前尺度比父场细多少、应退回直接父场还是更高祖先。为此，AI层必须把线性执行记录投影到显式递归场栈：

\[
\mathcal S_t^{field}
=
(\Phi_0,\Phi_1,\ldots,\Phi_{d_t}),
\]

\[
\Phi_k=
\langle
field\_id_k,parent_k,address_k,
\Gamma_k,\delta_k,\epsilon_k,\tau_k,
best_k,upper_k,evidence_k,residual_k,reopen_k
\rangle .
\]

至少分开：

- `d_t`：模型内递归深度，即已经打开多少层完整子场；
- `q_t`：在尺度可比较时，分辨率跨越的数量级；
- `w_t`：同层中心／分支宽度；
- `r_t`：交互复杂度或未解析耦合；
- `K_t`：剩余token、时间、计算和实验预算。

`F_d`不等于`d`个物理数量级；分支增多也不等于分辨率变细。没有这种分型，系统只能看到“一条很长的路”，无法识别自己是在增加结构层级、提高局部精度，还是横向扩张无关中心。

### 7.2 停滞检测、逐层整合与Unwind

候选停滞判据不是“文本很长”本身，而是连续若干步没有发生：

```text
偏序地址前进
或 闭合残差下降
或 有效证据增加
或 可达上界提高
```

一旦停滞、可达上界低于门槛，或上下文接近预算边界，当前子场先形成：

\[
\operatorname{Fold}(\Phi_k)
=
\langle
conclusion,evidence,best,upper,
residual,assumptions,reopen
\rangle ,
\]

再沿父指针逐层`Unwind`。回退目标不是固定层数，而是最近一个能够重新决策的祖先：

- 仍有未尝试的合法平级中心；
- 父场容差可以吸收当前缺口；
- 可以重新分配误差预算；
- 有权修改任务边界或闭合门槛；
- 当前分解已经被证据否定，需要更高层重构。

回卷不是遗忘。完整子场轨迹仍保存在外部记录中，主上下文只继承证据引用、最好结果、失败上界、未闭合债务和重开条件。只对已合法标量化、且“数值越大表示越满足要求”的审计分量`j`，设原门槛为`g_{\mathrm{old},j}`，而当前证据只支持`\hat m_{k,j}<g_{\mathrm{old},j}`：若父接口实际要求`g_{\mathrm{parent},j}\le\hat m_{k,j}`，应修正此前过严的传导；否则只能显式把该分量契约修订为`g_{\mathrm{new},j}\le\hat m_{k,j}`并形成新版本。该分量达标也不能替代其他审计分量和结构硬门，更不能在原标准下伪报完整闭合。

状态：上述结构是**用户明确方向经模型形式化后的Agent候选机制**，尚未实现或完成性能验证。

### 7.3 AI一般层与大语言模型层必须分开

AI一般层的问题是任务控制架构：是否保存契约、场栈、尺度、证据、预算、回卷和重开接口。它也适用于搜索器、规划器、机器人或混合智能系统。

大语言模型层的问题更具体：推理和工具经历主要以线性token序列进入有限上下文；如果层级状态只隐含在长文本中，压缩或截断后可能丢失父场地址、局部门槛和失败理由，从而在同一节点改写、补充、反驳、再补充，表现为语义振荡和过度工程化。

这不是对所有大语言模型的普遍失败定理。外部任务图、结构化内存、子Agent隔离、验证器、停止钩子和持久状态都可能缓解问题；是否有效取决于它们是否真正保存并使用了可回卷的层级地址，而不只是增加更多文本或更多模型调用。

## 八、检索是继承闭合，不只是补充上下文

[RAG](https://arxiv.org/abs/2005.11401)把参数记忆与外部非参数记忆结合，用于知识密集型任务。递归场解释进一步要求：

\[
\text{检索结果}
\neq
\text{已闭合接口}.
\]

检索到的论文、代码或结论还必须经过：

- 来源与版本核验；
- 适用条件匹配；
- 父场接口等价检查；
- 证据强度和误差检查；
- 失败时的重开地址记录。

因此“不要重复造轮子”的严格形式不是无条件复用，而是优先验证可继承接口，再决定调用、改造或重新展开。

## 九、“认知功能”改写为可检验能力

“AI没有认知功能”是哲学强判断，当前不作为已验证结论。为了工程验证，可把用户所说的任务结构治理能力暂时操作化为系统是否能够：

1. 显式表示任务场和父场契约；
2. 区分表示维度、模态维度、任务维度和搜索维度；
3. 估计当前分辨率是否足够；
4. 识别中心、硬门、接口和未闭合剩余；
5. 选择需要打开的位置而非全覆盖；
6. 用外部证据校验语言推断；
7. 保存尝试过的路径、失败原因和可复用接口；
8. 在契约满足时停止，在条件失效时重开。
9. 保存递归场栈，并区分递归深度、分辨率数量级、分支宽度和交互复杂度；
10. 检测局部停滞，把子场逐层压缩回卷到最近可重新决策的祖先。

这些能力可以逐项测试；是否应把它们称为“认知”仍属于哲学和认知科学开放问题。

## 十、AI发展的候选方向

用户提出的方向可改写为：

> AI系统应把探索中发现的未知维度，从不可审计的隐状态或一次性对话中，提取为有类型、可验证、可复用和可重开的场地址。

对应的工程载体可能包括：

- 外部知识库与检索；
- 多模态观察接口；
- 工具和实验执行；
- 结构化任务记忆；
- 动态计算深度；
- 领域验证器；
- 中心／依赖图；
- 技能和闭合接口库。

增加这些接口可能减少无关搜索并提高样本或计算效率，但不能自动保证更快收敛。若新增模态、工具或记忆没有正确路由和验收规则，也可能扩大搜索空间和错误传播。

用户口述中的“Lens AI”未能唯一对应到某项公认技术，暂不写入具体技术谱系；可能指多模态、视觉接口、Agent治理或某个产品，需后续明确。

## 十一、可检验假说

### H1：契约化分辨率减少无效展开

在同等任务正确率和证据要求下，显式提供`\delta、\epsilon、\tau`的Focus型Agent应减少无关检索、工具调用和展开节点。

### H2：接口继承优于从零生成

对已有成熟文献、代码或公式的任务，先执行接口匹配和证据核验，应比无检索的纯生成减少重复推导和事实错误。

### H3：选择性精化优于固定全深度

在任务难度不均匀的数据集上，动态选择展开深度应以更低平均计算成本达到与固定深度系统相当的闭合率。

### H4：有类型剩余改善重开

把失败区分为缺证据、接口失效、分辨率不足、中心遗漏、交互遗漏和真实不可行，应比统一“继续思考”更快定位下一次有效展开。

### H5：显式场栈改善长任务恢复

在相同上下文预算下，保存`field_id／parent／address／scale／closure／reopen`的Agent，应比只保存线性对话摘要的Agent更准确地恢复当前任务层级、父场要求和下一合法地址。

### H6：分层回卷减少局部振荡

在具有不等深分支和不可达局部门槛的任务上，使用停滞检测、`Fold`摘要和最近可决策祖先回退的Agent，应减少同一节点重复推理、无效工具调用和过度工程化，同时不显著降低父任务正确率。

这些都是**待实验工作假说**，尚未由本项目实现或验证。

## 十二、当前结论

递归场视角不把大模型描述成“真的穷尽全部世界维度”，而把其局限定位为：

\[
\boxed{
\text{高维表示能力}
\not\Rightarrow
\text{拥有任务相对的分辨率、结构地址和闭合判断}
}
\]

大模型可以生成、组合和检索候选；父场契约、Focus选择、证据工具、误差预算、停止规则和可重开记忆共同决定这些候选能否形成可审计的研究闭合。

本轮进一步得到：

\[
\boxed{
\text{监测到停滞}
\not\Rightarrow
\text{知道应回退到哪里}
}
\]

只有把执行轨迹映射为可寻址的递归场栈，监测器才可能依据父子层级、尺度、可达上界和父容差实施分层回卷。该结论目前是工程设计判断和待验证假说，不是已实现能力。
