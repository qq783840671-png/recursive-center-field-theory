## 论断标记

- `[D]`：定义或已经实现的协议行为；
- `[H]`：工作假设；
- `[O]`：开放问题。

阅读时应区分哲学论证、方法定义、工程实现和经验验证。某个 Skill 可运行，不等于整个哲学体系已经被经验确证。
