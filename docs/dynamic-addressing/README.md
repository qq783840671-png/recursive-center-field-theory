# 递归动态寻址理论

> 状态：理论候选（v0.12-draft，2026-08-29）。本目录把“递归中心场偏序动力模型”中分散的地址定义、生成规则、运动谱系和审计边界展开为一个独立中层理论，并已加入完整场多中心归属、过程内功能寻址、闭合失效和版本谱系。它尚未经过跨分析者标定和跨领域经验比较；当前程序测试只证明结构记录与迁移约束。

## 一、理论位置

本目录不建立一套与递归中心场论竞争的新根理论。它从既有总模型中的“地址形式语义”和“地址运动／版本维护”合法展开而来：

```text
递归偏序多中心动态场域论
├─ 场：限定对象、目标、尺度和证据边界
├─ 中心与必要偏序：提供承重位置和合法根路径
├─ 递归展开／压缩：产生层级和可重开接口
├─ 动力、闭合与剩余：推动地址生成、失效和重构
├─ 完整场多中心系统：保存中心归属、中心间义务、联合闭合与谱系
└─ 递归动态寻址理论：使上述运动获得可定位、可追踪的结构身份
        ↓
   构造型Focus导航与修订／历史sidecar导入／地址引擎／知识地址／多 Agent 编排等应用
```

地址不是与“场、中心、偏序、递归、动力”并列的第六个本体核心，而是这些核心共同生成的结构坐标层和运动可观测层。Focus是当前第一套运行应用，不等于地址理论本身；v0.18在父任务过程中只为导航、约束、证据、记忆或重开审计生成地址，并维护一个`selected_center_ref`及必要`peer_center_refs`。历史sidecar与两阶段运行时仍保存执行后导入和投影—返回兼容接口，但不再定义新调用。

最容易混淆的分账是：普通潜在前沿`P_t^{latent}`已经有合法地址，只是本轮不要求展开；潜在剩余`Λ_t`是尚未激活的差异记录，可以绑定合法地址、候选地址或暂时无地址，但它本身不是地址、没有`[◇]`模态。

## 三、最小中心轴

```text
A 形成场与对象身份
→ B 恢复中心、偏序和根路径
→ C 赋予并标定动态地址
→ D 通过展开、聚焦、压缩和更新生成地址运动
→ E 审计模态、剩余、证据和版本谱系
→ A′ 返回可追踪的新场版本
```

## 四、当前可守住的主张

- 地址是对象在特定场、功能位置、根路径、递归路径和版本中的结构身份。
- 地址由真实的场形成与地址运动生成，不是人工随意追加的分类编号。
- 同一对象可在不同场中拥有不同地址；地址变化不等于对象消失。
- 同一功能地址可以服务一个或多个中心，通过`center_membership`保存归属，不为每个中心复制对象和逻辑地址。
- 多中心的候选、活动、联合闭合和运动谱系必须分开保存。
- 完整场可以保存多个平级或并行中心；构造型Focus一次只运行一个选定中心并保留必要平级接口，不得为满足格式补造中心。其他中心不得被删除，也不得并入当前`Ready_t`。
- 稳定`address_id`不包含`center_membership`；共享地址的逐中心义务满足状态必须分别保存。
- 保留逐中心闭合、失效、重开与谱系向量的`Compose`仍是多中心包装器，不是复合单中心。
- 每个已实现地址必须绑定非空执行或分析证据；Focus投影必须绑定源场／中心系统版本并返回`ProjectionCertificate／FocusReturn`。无论哪种运行形态，中心局部闭合都不等于完整场闭合。
- 新地址先表示合法潜在位置，只有执行并通过审计后才能声明相应结果已经实现。
- 地址、模态、前沿、剩余吸收状态、证据和版本必须分别保存。
- 压缩可以隐藏子场细节，但必须保留接口、证据、版本和重开地址。
- 旧地址退役、迁移、分裂或合并后，历史意义和旧新谱系仍须保留。

## 五、当前不主张

- 不主张现实中的一切对象天然携带唯一地址。
- 不主张数字路径本身能够证明真实因果、中心或必要偏序。
- 不主张地址越深越重要、越真实或越接近终极真理。
- 不主张当前状态助手已经能从自然语言自动生成正确地址。
- 不主张当前schema、Focus Skill或Address Engine已经实现完整场多中心联合调度；v0.18实现的是任务相对的单中心过程投影，不是自动生成现实全景。
- 不主张动态寻址已经优于知识图谱、工作流、HTN、RAG或其他既有系统。
- 不把当前理论工作区直接当作已经完成的地址引擎、数据库模式或公开标准。

## 六、维护规则

1. 总理论改变场、中心、偏序、递归或动力定义时，先检查本目录接口是否失效。
2. 地址理论发生变化时，只在突破总理论接口时才向上修改总模型。
3. Focus、知识检索或多 Agent 应用出现失败时，先判断是应用缺陷、协议缺陷还是地址理论反例。
4. 强主张必须标明为“用户明确”“当前理论定义”“已实现”“工作假设”或“开放问题”。
5. 未完成标定或无合法根路径的地址只能作为地址假设，不得进入已实现下闭集。
