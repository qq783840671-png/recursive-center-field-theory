# 递归中心场域论

[English](README.md) · 冻结候选版 `v0.1.0-alpha.3` · 个人非商业公开分享

> 不是给世界一个永恒正确的中心，而是保留不断形成、检验和重建中心的能力。

这个仓库公开分享一套仍在发展的哲学—方法体系，以及三项可以实际使用的 Codex Skill。共同内核是**递归中心场偏序动力模型**：相对于当前任务形成场，恢复候选承重中心与必要偏序，递归打开或压缩子场，生成可追踪的动态地址，沿合法前沿行动，再让证据和剩余推动下一版本。

它是个人研究和实践分享，不是商业服务。公开的主要目的，是让更多人能够理解、试用、批评、复现，并在非商业场景中继续发展它。

## 一套体系，三个入口

| 入口 | 公开内容 | 当前状态 |
|---|---|---|
| [理论与方法论](docs/methodology/README.md) | 哲学基础、场—中心共构、必要偏序、递归运动、闭合与剩余驱动重构 | 正式公开草稿 |
| [递归动态寻址](docs/dynamic-addressing/README.md) | 给对象、关系和状态生成场相对、版本化、可重开的结构地址 | 理论 `v0.1`；含实验引擎 |
| [三个 Codex 插件](#安装与使用) | Focus、Address、Distill 可分别安装和调用 | 当前版本冻结快照 |

它们不是平面并列的三个孤立产品，而是同一体系的不同展开：

```text
哲学思想
→ 递归中心场偏序动力方法论
→ 动态地址生成方法
→ Focus / Address / Distill 应用
→ 证据、剩余与下一版理论
```

- **Focus** 是主打应用：帮助人和 Agent 定场、找中心、恢复必要偏序、按不同深度展开，并继续执行和审计。
- **Address** 把动态地址方法变成可计算的赋址、登记、查询与审计工具。
- **Distill** 是较小的派生应用：把零碎对话中的稳定认识、决定、冲突、剩余和来源保守地合并到唯一知识主文件。

压缩与展开是方法论内部的运动环节；沉淀不是另一套核心方法论。

## 安装与使用

仓库未来发布到 GitHub 后，可添加其中的插件市场：

```bash
codex plugin marketplace add qq783840671-png/recursive-center-field-theory
```

重启 Codex，在 Plugins 中按需安装：

- `RCF Focus`
- `RCF Address`
- `RCF Distill`

三个插件只包含本地 Skill 和脚本，不增加连接器、托管服务、MCP 服务或外部认证依赖。

## 理论、方法和应用的边界

公开文档用三类标记区分论断：

- `[D]`：当前版本的定义或已经实现的协议行为；
- `[H]`：仍需比较、实验或外部验证的工作假设；
- `[O]`：尚未闭合的开放问题。

本项目不宣称已经达到 SOTA、普遍优于现有方法、自动恢复真实因果、实现无损无限上下文、解决一般规划，或证明一种普遍本体论。显式结构可能帮助某些长程任务，也可能把错误场或错误中心稳定下来，因此场契约、中心候选、证据和剩余都必须允许审计与修订。
