# 递归偏序多中心动态场域论

[English](README.md) · 本地发布候选 `v0.4.0-alpha.1` · 系统快照 `2026.08.29-rcf.1` · 尚未上传 · 个人非商业公开分享

> Focus在Codex执行父任务的过程中参与建构：形成当前投影、推进必要前沿，在证据变化时使旧闭合失效，并保存版本谱系。

本仓库公开一套仍在发展的哲学—方法—工程体系。它以任务相对的场契约为边界，区分完整场的多中心结构与 Focus 的单中心偏域运行；在选中中心内恢复必要偏序，按需要递归打开一层子场，生成版本化动态地址，并用证据、剩余、折叠和回卷维护后续版本。

这是个人研究项目和可验证的工程原型，不是自然科学定律、完备本体论或商业服务。公开目的是让定义、实现、测试、局限和历史都可以被检查、复现和批评。

### 两个容易混淆的“潜在”概念

- 普通潜在前沿`P_t^{latent}`：已经存在合法地址，但本轮不要求展开；尚未实现时通常保持`[◇]`。
- 潜在剩余`Λ_t`：尚未激活的新差异，可以绑定合法地址、地址候选或暂时无地址；它本身不是地址，因此没有`[◇]`模态。

一句话：`P_t^{latent}`是“位置已确定，本轮不做”，`Λ_t`是“发现了差异，位置或处理方式尚待判断”。

## 三个 Codex 插件

- **RCF Focus**：通过`FORM → DRIVE → REVISE → FOLD`维护实时任务场；有结构差异时改变下一步行动，使过时闭合失效，并保存版本和分支。
- **RCF Address**：生成、登记、查询和审计场相对、版本化、可重开的结构地址。
- **RCF Distill**：把对话中的稳定命题、决定、冲突、剩余和来源保守地合并到唯一知识主文件。

本候选还为 Focus 提供 `$focus` 调用别名。三个插件只含本地 Skill 和脚本，不增加连接器、托管服务、MCP 服务或外部认证。

## 论断边界

- `[D]`：定义或已由当前代码／测试实现的协议行为；
- `[H]`：仍需比较、实验或外部验证的工作假设；
- `[O]`：尚未闭合的开放问题。

当前v0.18运行时已经实现建构型定场与下一前沿决策、有类型知识差异、依赖作用域失效、不可变闭合版本与分支、动态地址、递归`Fold／Unwind`及选中中心／完整场闭合分离。历史sidecar与两阶段状态继续用于导入和审计。它尚未实现领域真值自动发现、完整多中心生命周期、跨任务全景重新汇合、自动重投影或经验性能优势证明。

本项目不声称 SOTA、普遍优于现有方法、自动恢复真实因果、无损反演高维现实、解决一般规划，或证明跨物理尺度的统一本体。数学和物理比较是结构参照，不是本体证明。
