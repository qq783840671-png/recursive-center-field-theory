# RCF Focus

本插件封装 `recursive-center-field-dynamics` Skill，是体系当前的主打应用。它面向目标、依赖、所需深度或执行路线会继续变化的复杂任务。

最小调用：

```text
用 Focus：先给出候选 F0 偏序轴；我确认后，再建模并执行这个任务。
```

新问题场会先停在 F0 确认点。确认只固定当前根目标，不代表已经闭合；只要仍有阻塞剩余、禁止转换或当前无地址结果，就不能伪装成可直接执行的稳定场。

完整案例见[开源缺陷修复](../../examples/open-source-defect-repair/README.md)。
