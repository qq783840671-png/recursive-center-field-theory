# RCF Focus

RCF Focus is the constructive execution layer of Recursive Center-Field Theory. It runs inside the parent task through:

`FORM → DRIVE → REVISE → FOLD`

The parent model retains execution authority. Focus maintains a task-relative field, selects one current center, returns one necessary next frontier, and changes the next action when a structural difference exists. It does not add a second permission gate.

When new evidence conflicts with an earlier conclusion, Focus records a typed knowledge delta, identifies the smallest affected scope, invalidates dependent closure, preserves the earlier version, and either revises locally, reopens an interface, reframes the field, splits a branch, or unwinds to an ancestor.

If Focus has no structural difference to contribute, it returns `NOOP`. A latent residual is a difference record, not an address, and never receives `[◇]` merely to make the output look formal.

## Evidence boundary

The runtime and contract tests verify recorded state transitions, dependency invalidation, version lineage, and compatibility behavior. They do not prove that an inferred center is uniquely true, that a domain conclusion is correct, or that Focus outperforms other methods without independent comparison runs.
